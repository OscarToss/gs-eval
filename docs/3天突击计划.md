## 4. 数据侧已经确认的事实（不要重复劳动）

| 事实 | 数值 |
|---|---|
| 数据集 | BGLR 包 `wheat`，599 小麦品系 × 1279 个 DArT 标记 × 4 个环境 |
| 基因型编码 | 只有 **0 和 1** 两种取值（DArT 是显性标记，不是 SNP 的 0/1/2） |
| 表型 Y | 4 列，每列**已经标准化**（均值 0，标准差 1） |
| `wheat.sets` | 10 个组，每组 50–73 个品系 —— **这是环境/试验分组，不是家系** |
| 亲缘矩阵 A | 599×599，对角线均值 1.98，取值范围 0 ~ 2 |
| 数据来源 | CRAN 的 BGLR_1.1.4.tar.gz（4.7 MB），Python 用 `tarfile` + `rdata` 直接解析，不需要装 R |

### 已经跑出来的第一批数字（可复现）

用最大似然 / REML 估出的性状遗传力 h²：

| 环境 | h² | 记号 |
|---|---|---|
| env1 | 0.325 | |
| env2 | 0.302 | |
| env3 | 0.425 | |
| env4 | 0.363 | |

**这个数字与作物育种文献里常见的 h² = 0.3–0.7 吻合**，说明数据是真的、流程是对的。

### 一个必须写进报告的"意外"

5 折随机交叉验证的预测精度 r 只有 **0.11–0.24**，比"由 h² 反推的预期"（约 0.4）低。
目前**原因未确定**。候选解释（都需要动手验证，不许猜）：

1. DArT 是显性标记，信息量天然低于 SNP，亲缘矩阵估计得不准
2. 训练集只有 ~479 个品系，而标记有 1279 个，标记效应估计误差大
3. `wheat.sets` 的 10 个组之间亲缘关系几乎一样（组内/组间比 0.91–1.06），
   说明这份数据**没有家系结构**，不能直接做"分组 CV"的对照

**第 3 条是个大发现**：课程设计里"随机 CV vs 分组 CV 精度明显不同"这个预期，
在 wheat 数据上**不成立**，因为它的分组不是家系。
要么改用按亲缘关系聚类人工造组，要么换一个真有家系结构的数据集。
—— 这本身就是一份可以交给老师的"选题建议"的内容。
