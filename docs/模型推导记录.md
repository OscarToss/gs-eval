# 模型推导记录

记下 GBLUP 实现过程里的两个坑，免得以后重新踩。

## 1. 目标函数必须带 logdet

GBLUP 模型：`y = μ + u + e`，`u ~ N(0, Gσ²u)`，`e ~ N(0, Iσ²e)`。
令 `γ = σ²e / σ²u`，则 `u` 的 BLUP 解是 `û = G(G + γI)⁻¹(y - μ)`。

**坑**：最初用"最小化残差平方和"来定 γ，结果 γ 跑到边界，h² 算成 0.000。

原因：只最小化 RSS 时，γ→0 会让残差→0，是数学上合法的下降方向，
所以最优解永远在边界，估计出的方差组分没有意义。

**正确做法**：用（RE）ML 目标函数。对 `G` 做特征分解 `G = VΛVᵀ`，令 `dᵢ = γ + λᵢ`：

```
-2logL = n·log(RSS/n) + Σ log(dᵢ)          (ML)
-2logL = n·log(RSS/n) + Σ log(dᵢ) + log(Σ 1/dᵢ)   (REML)
RSS    = Σ (Vᵀy_c)ᵢ² / dᵢ
```

`Σ log(dᵢ)` 随 γ 减小而减小（更负），正好抵消 RSS 项，使最优点落在内部。

实测（env1，wheat 数据）：

| γ | RSS | REML 目标 | 5 折 CV 精度 r |
|---|---|---|---|
| 0.001 | 4148.7 | 406.97 | 0.2879 |
| 2.07 | 168.1 | **-27.83** | 0.2596 |
| 1e4 | 0.06 | -1.96 | 0.1746 |

RSS 最小的点（γ=1e4）CV 精度最差。REML 选中的 γ=2.07 接近 CV 最优点（0.2879）。

补充：γ 取极小值时 CV 精度并没有崩，因为 `G` 本身病态（特征值 9.8e-4 ~ 256），
矩阵求逆自带正则化。所以这个例子里"RSS 最小"的代价体现在大 γ 一侧。

## 2. 留一交叉验证公式写错过一次

第一版自己推了个"留一残差"公式，跑出来 γ 越大精度越接近 **1.0000**。

查出来：那个式子在特征基下化简后，分子分母是同一个量，等于自己和自己比相关。

**教训**：精度跑到 0.9 以上、或者随参数单调趋近 1，先怀疑公式，别高兴。

改用真正的 K 折（切分训练/测试集，重新拟合）后数值正常。
