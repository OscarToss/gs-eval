### 由此踩到的第一个真实的坑（值得记住一辈子）

`pip install` 一开始全部失败，报错里有关键词：

```
ProxyError('Cannot connect to proxy.', ... [WinError 10061] 由于目标计算机积极拒绝，无法连接)
```

**读报错的方法**：`[WinError 10061]` = 连接被拒绝 = 你要连的那个地址上没有程序在听。再看地址是 `127.0.0.1:7897`，那是本机代理端口。

三种修法，按优先级：

1. 把 Clash / FlClash 的**内核**打开，让 7897 真的在监听（这样以后 Google、HuggingFace 也能上）
2. 临时清掉代理变量，走直连：
   ```powershell
   Remove-Item env:HTTP_PROXY, env:HTTPS_PROXY, env:ALL_PROXY
   ```
   **本项目的所有 pip 命令都用了这一招**，因为 GitHub / PyPI / 清华镜像直连都通。
3. 永久把用户级代理变量删掉（会影响其它程序，慎用）

## 2. 最小必要知识（只有 5 条）

**① 终端（Terminal）**
一个用打字而不是点鼠标来指挥电脑的窗口。VS Code 里按 `` Ctrl+` `` 就能打开。
所有命令都在**项目目录**下执行，所以先 `cd D:\GS\gs-eval`。

**② Python 解释器（interpreter）**
真正执行 `.py` 文件的那个程序。命令写成 `解释器路径 脚本路径`：

```powershell
D:\GS\gs-eval\.venv\Scripts\python.exe scripts\00_prepare_data.py
```

**③ 虚拟环境（venv）**
给一个项目单独准备的一个"Python 副本 + 一套第三方库"。好处：项目 A 装 pandas 3.0、项目 B 装 pandas 2.0 互不打架；你把整个文件夹拷给别人，别人 recreate 一下就能复现。
创建（一次性）：`python -m venv .venv`
启用（每次开新终端可选）：`.venv\Scripts\Activate.ps1`
**注意**：Python 3.11 之后**不需要** `pip install virtualenv`，`venv` 是自带的。

**④ pip 与镜像**
`pip` 是 Python 的"装库工具"。国内直连 PyPI 慢，用清华镜像：

```powershell
python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple pandas
```

**慢和失败是两件事**：慢 → 换镜像；报 `WinError 10061` → 代理问题。

**⑤ 第三方库**
别人写好的、可以 `import` 的代码包。本项目只装 6 个：
`numpy`（数字数组）、`pandas`（表格）、`scipy`（统计）、`scikit-learn`（机器学习）、`matplotlib`（画图）、`lightgbm`（梯度提升树）。

## 3. 一个能直接跑通的完整例子

已跑通，命令与真实输出如下。

**建虚拟环境 + 装库：**

```powershell
cd D:\GS\gs-eval
C:\Users\aosik\AppData\Local\Programs\Python\Python311\python.exe -m venv .venv
Remove-Item env:HTTP_PROXY, env:HTTPS_PROXY, env:ALL_PROXY
.venv\Scripts\python.exe -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple `
    numpy pandas scipy scikit-learn matplotlib lightgbm rdata
```

装完的版本（写进 `requirements.txt` 用）：

```
numpy==2.4.6
pandas==3.0.6
scipy==1.17.1
scikit-learn==1.9.1
matplotlib==3.11.2
lightgbm==4.7.0
rdata==1.1.0
```

**跑数据准备脚本：**

```powershell
.venv\Scripts\python.exe scripts\00_prepare_data.py
```

**真实输出（数据体检报告）：**

```
基因型矩阵 X : (599, 1279)   <- (品系数, 标记数)
表型矩阵   Y : (599, 4)      <- (品系数, 环境数)
亲缘矩阵   A : (599, 599)

X 的取值种类: [0, 1]
X 中 1 的比例: 0.283
```

这就是课程里写的那个基准数据集：**599 个小麦品系 × 1279 个 DArT 标记 × 4 个环境**。
DArT 标记的基因型是 0/1 编码（不是 SNP 那样 0/1/2），所以标记矩阵只有 0 和 1 两种取值——这点后面写代码时很关键。

## 4. 数据从哪来（可复现，不是"我同学给的"）

BGLR 是 R 语言里做贝叶斯回归的包，课程里提到的 wheat 数据集就打包在它里面。
本机没装 R，但 **CRAN（R 的官方软件仓库）能下到 BGLR 的源码压缩包，里面直接就有 `data/wheat.RData`**：

```powershell
# 下载（清华镜像，约 4.7 MB）
Invoke-WebRequest -Uri "https://mirrors.tuna.tsinghua.edu.cn/CRAN/src/contrib/BGLR_1.1.4.tar.gz" `
    -OutFile data\raw\BGLR_1.1.4.tar.gz
```

然后用 Python 的 `tarfile` 取文件、`rdata` 库解析 R 的二进制格式，转成 CSV。
`scripts/00_prepare_data.py` 把这三步写进了一个脚本——**别人拿到这个仓库，也能跑出同样的 CSV**。
