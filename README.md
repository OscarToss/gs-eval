# gs-eval

基因组选择（Genomic Selection, GS）预测精度的评测。

## 这份代码在做什么

GS 是用全基因组标记去预测个体的表型值，从而在苗期就决定选谁留种。
领域里一个长期问题是：**论文报告的预测精度互相不可比**，因为评测设计不统一
（测试集和训练集的材料是不是亲戚，精度能差好几倍）。

这个项目用 GS 领域最经典的公开基准数据集，把"同一份数据在不同评测设计下精度如何变化"
算出来、画出来。

**这是"方法评测"，不是"开发新模型"。**

## 数据

| 项目 | 说明 |
|---|---|
| 来源 | BGLR 包的 `wheat` 数据集（CRAN 上的 `BGLR_1.1.4.tar.gz`） |
| 规模 | 599 个小麦品系 × 1279 个 DArT 标记 × 4 个环境 |
| 基因型编码 | 0 / 1（DArT 是显性标记，不是 SNP 的 0/1/2） |
| 表型 | 4 列，每列已按环境标准化（均值 0，标准差 1） |
| `wheat.sets` | 10 个试验分组，每组 50–73 个品系。**是试验环境分组，不是家系** |

下载（约 4.7 MB）：

```powershell
Invoke-WebRequest -Uri "https://mirrors.tuna.tsinghua.edu.cn/CRAN/src/contrib/BGLR_1.1.4.tar.gz" `
    -OutFile "data/raw/BGLR_1.1.4.tar.gz"
```

## 怎么跑

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python scripts/00_prepare_data.py
```

输出：`data/wheat_X.csv`、`wheat_Y.csv`、`wheat_A.csv`、`wheat_sets.csv`。

## 结果

**遗传力 h²**（GBLUP + REML 估计）：

| 环境 | h² |
|---|---|
| env1 | 0.325 |
| env2 | 0.302 |
| env3 | 0.425 |
| env4 | 0.363 |

落在作物育种文献常见的 0.3–0.7 区间内。

**预测精度 r**（5 折交叉验证）：

| 评测设计 | env1 |
|---|---|
| 随机 5 折 | 0.11 – 0.24 |
| 按 `sets` 分组 5 折 | 0.05 – 0.24 |

## 目前没搞懂的两件事

1. **预测精度 0.15 左右，比由 h² 反推的预期（约 0.4）低不少。** 候选原因：
   DArT 标记信息量低、训练集只有 ~479 个品系而标记有 1279 个、亲缘矩阵估计不准。
   都没验证。

2. **随机 CV 和分组 CV 的精度几乎一样**，和文献里"评测设计影响很大"的说法对不上。
   查了原因：这 10 个组之间的平均亲缘关系和组内几乎相同（比值 0.91–1.06），
   说明 `sets` 不是家系划分，分组 CV 并没有切开亲戚。
   所以要验证这个结论，得换一个真有家系结构的数据集，或者按基因组亲缘关系人工聚类分组。
